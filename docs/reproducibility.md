# Reproducibility limits and exclusions

This release preserves source code and selected editable graphical source. Its checks cover export integrity and syntax, not an end-to-end reproduction or independent scientific verification.

- **Data absent:** no raw/restricted inputs, public-source snapshots, genotype reference panels, fine-mapping bodies, harmonized databases, frozen numerical results or figure-result TSVs are included. Acquisition scripts and layout inventories identify expected locations but do not grant data access or establish upstream redistribution rights.
- **Historical input bindings:** source files retain frozen dates, exact input/output directories, hash gates and overwrite refusals. The original input hashes describe historical runs. Path-only export edits alter code/config hashes, so historical execution bindings cannot be reused as proof of a new run. Reproduction requires a new, explicitly recorded binding after obtaining the exact inputs; do not bypass the checks.
- **Figure preservation chain:** clean-v3 builders hash old artwork, tables and captions before/after drawing. The extra historical source scripts are included, but old binary artwork, complete caption documents and result extracts are omitted. The final editable SVGs and the four exact pre-Arial inputs are present without geometric or scientific changes. Full de novo figure reconstruction was not tested. The final Arial export still needs separately supplied fonts, Chromium, Playwright and PDF libraries.
- **External checker:** historical `build_circular_figures.R` and final `export_arial_main_figures.py` invoke `tools/diagram-design/self_check.py`. This external, non-study validation helper is not redistributed; its location is documented as an unresolved validation dependency, not silently replaced with a passing check. A complete final-export run also requires this helper.
- **External software absent:** CC-GWAS, LAVA/LDSC source, LD panels, HTSlib/liftOver binaries and chains, browser binaries, proprietary fonts and runtime environments are not copied. Exact liftOver/runtime details are incomplete for some earlier stages. There is no validated all-stage lockfile.
- **Scientific scope:** observational association correspondence is not causal proof. T12 remains partial; T13/T14, BBJ signal-level validation, Graves-only ophthalmopathy modifiers and formal target/MR/PheWAS admission remain limited or unavailable as described in the README. No analysis or scientific status was changed for export.
- **Excluded project material:** local Git history/configuration and tools, research-dashboard state, AGENTS/agent instructions, task reports/HTML, manuscripts, submission files, correspondence/contact packages, credential/private files, unrelated studies, downloaded third-party code and binary assets. Scripts 66-90 concern later resource-qualification/contact/decision work outside the selected reported analysis lineage and are excluded; no selected script imports those helpers.

No data, statistical, numerical-integration, graphical rerender or complete pipeline test was run during release preparation. Relevant test source is included, but importing those test modules would also import analysis modules, so only static parsing was performed. Previously recorded source-run checks are historical evidence, not new release checks.
